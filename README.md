## Tech Stack

- **Framework**: [React 19](https://react.dev/) with [Vite 6](https://vitejs.dev/)

- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Modern Vanilla CSS Design System with dark mode luxury aesthetics, glassmorphism, responsive grids, and micro-interactions
- **Hosting / Deployment**: [Vercel](https://vercel.com/)

## Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/jayantvaibhavspj/jobgen_prime_talent_website.git
cd jobgen_prime_talent_website
npm install
```

### Local Development

```bash
npm run dev
```

Visit `http://localhost:5174` in your browser.

### Production Build

```bash
npm run build
```

The compiled and optimized assets will be generated in the `dist/` directory.

## Deployment

Configured for seamless deployment on **Vercel** with full SPA routing rewrites handled via `vercel.json`.
